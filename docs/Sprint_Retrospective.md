# Sprint Retrospective

## What Went Well?
- The work was divided into small, prioritized user stories.
- The Iris dataset and a baseline Decision Tree model made the experiment manageable.
- The train/test split and fixed random seed make the evaluation reproducible.
- Scrum documentation makes roles, plans, and outcomes visible.

## What Problems Occurred?
- Missing Python packages can prevent the script from running.
- The accuracy result must be generated and recorded after execution.
- Documentation and code outputs need to stay synchronized.

## Improvements for the Next Sprint
- Install dependencies before Sprint work begins.
- Add automated tests for model loading and prediction shape.
- Track experiment results and model versions.
- Review the backlog at the end of every Sprint and reprioritize based on feedback.
