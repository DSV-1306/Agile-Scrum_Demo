# Product Backlog — Iris Flower Classification

**Product goal (Product Owner):** Develop an Iris Flower Classification model with at least 95% accuracy.

| ID | User Story | Priority |
|---|---|---|
| US1 | Download/load Iris Dataset | High |
| US2 | Clean and prepare dataset | High |
| US3 | Train Decision Tree Model | High |
| US4 | Evaluate accuracy | Medium |
| US5 | Save trained model | Medium |
| US6 | Prepare documentation | Low |

## Why are High Priority tasks selected first?
- The dataset is required before any training can begin.
- Data preparation helps ensure reliable input to the model.
- Training the model delivers the core value requested by the Product Owner.
- Evaluation and model saving follow once a model has been trained.
- Documentation is important, but it does not block the first working model.
