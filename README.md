
# MLOps Agile Demo — Iris Flower Classification

## Aim

To demonstrate Agile methodology and the Scrum framework through an MLOps project that trains and evaluates a Decision Tree model for Iris flower classification.

## Product Goal

Develop an Iris Flower Classification model with at least 95% accuracy.

## Installation

Create and activate a virtual environment in Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install the dependencies:

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Execute the Model

Run the following command from the project root:

```powershell
python src/iris_demo.py
```

## Machine Learning Workflow

1. Load the Iris dataset.
2. Separate features and target labels.
3. Split the data into training and testing sets.
4. Train a Decision Tree classifier.
5. Generate predictions.
6. Calculate accuracy and classification metrics.
7. Save the trained model.
8. Generate an accuracy report.

## Actual Execution Results

- Dataset: Iris dataset
- Total samples: 150
- Training samples: 120
- Testing samples: 30
- Algorithm: Decision Tree Classifier
- Test accuracy: 100.00%
- Correctly classified test samples: 30 out of 30

The reported accuracy was obtained using an 80:20 train/test split with `random_state=42`. It applies to this specific test split and does not guarantee identical performance on all unseen data.

## Generated Outputs

- `models/iris_decision_tree.joblib` — saved trained model
- `reports/accuracy_report.txt` — accuracy, confusion matrix, and classification report

These outputs are generated by running the Python script. The `.joblib` file is excluded from Git tracking by the current `.gitignore` configuration.
